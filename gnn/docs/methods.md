To classify tumors by treatment response, we constructed per-tumor graphs using the PhosphoAtlas 2.0 KSP network augmented with HTKAM connections, comprising 2,944 gene nodes and 14,043 directed kinase–substrate edges. For each of 44 tumor samples, every node is assigned a four-dimensional feature vector consisting of the tumor-specific normalized kinase activity score (CD score) measured by HTKAM, together with the in-degree, out-degree, and in-degree centrality of the node, and each tumor is paired with a binary treatment label (untreated as class 0, ENC+PAN-treated as class 1). Kinase identifiers are standardized across data sources through a manual mapping (for example, NME → NME1 and THAP12 → PRKRIR), and missing activity values are imputed as zero to reflect the absence of detectable catalytic activity. Because initial training of a graph convolutional network directly on the raw HTKAM matrix produced unstable behavior, with the model frequently collapsing to majority-class prediction, we introduce a denoising step in which a fully connected autoencoder (TumorAE) is trained on the 44 × 192 tumor-by-kinase matrix, compressing each activity profile into a 16-dimensional latent representation through hidden layers of size 128 and 32 before reconstructing it symmetrically with a mean squared error loss. The reconstructed activity values are then substituted for the raw activity feature in the per-tumor node feature matrices, while the topology-derived features are left unchanged.

For tumor classification, we use a deliberately small graph neural network (TumorGNN_Tiny) chosen to match the limited sample size, consisting of a single graph convolution layer that maps each four-dimensional node feature vector to an eight-dimensional embedding, followed by ReLU activation, a global mean pooling layer that aggregates the per-node embeddings into a tumor-level representation, and a linear classification head producing logits for the two treatment classes. The model is trained with the Adam optimizer and cross-entropy loss, and a logistic regression classifier fit on the flattened HTKAM vector per tumor is included as a non-graph baseline to assess the contribution of network topology beyond the kinase activity measurements themselves. Owing to the small sample size, performance is evaluated using leave-one-out cross-validation (LOOCV), with each fold training a fresh model on the remaining 43 tumors and early stopping triggered after ten consecutive epochs without improvement in held-out loss. To identify the kinases that most strongly drive the model's predictions, we compute input-level gradient saliency scores by back-propagating the cross-entropy loss to the node feature tensor, recording the absolute gradient with respect to each node's activity feature, averaging across all tumors, and filtering to retain only nodes that appear as kinases in the KSP network, producing a prioritized ranking of signaling proteins whose activity most strongly influences the treatment-class decision.
